# Public documentation

Keep guides focused on building and playing the port, understanding its current
gameplay and code, and contributing without changing original behaviour.

Use current method names and high-level BattleTech descriptions. Graphics and
audio use their own domain language. Keep build commands and feature claims
consistent with the shipped source.

All public guides belong under `docs`, apart from the root project README.
Source and headers belong under `src`; build-system entry files stay at the root.
Historical notes, decompiles, annotations, Reko metadata, generators, ledgers,
research utilities and verification suites belong in the reverse-engineering
repository. Do not mirror them here.

Asset editing, export/import and workshop CLI instructions belong in
[MechwarriorTools](https://github.com/Elthial/MechwarriorTools).
Never publish game installations, private saves or raw captured resources.
