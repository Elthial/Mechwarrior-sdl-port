Current gameplay explanations live in the [gameplay topic index](gameplay/README.md).
They use actual suffix-free method names and describe gameplay responsibilities,
not registers, storage addresses or decompiler expressions.

Historical conversion reports, audits and detailed research notes belong in the
separate reverse-engineering repository. This port contains current guides,
source and the information needed to use it. Annotations, generators and
verification infrastructure belong only in the reverse-engineering repository.
Raw ASM exports and original executables remain private and excluded.

Asset-format authoring and workshop/CLI instructions belong in the separate
[MechwarriorTools documentation](https://github.com/Elthial/MechwarriorTools/blob/main/docs/README.md).
